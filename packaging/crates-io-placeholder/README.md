# neoscad

This is the official name reservation for **NeoSCAD** on crates.io.

NeoSCAD is a ground-up reimplementation of OpenSCAD, the programmable solid
CAD tool: its language, its command-line flags and its test suite, with a
JSON-RPC server, a Model Context Protocol server for AI agents and a
language server built in. See [neoscad.org](https://neoscad.org) and
[github.com/neoscad/neoscad](https://github.com/neoscad/neoscad).

This crate contains no code. The real `neoscad` command-line tool will be
published under this name; until then, install it from the
[releases](https://github.com/neoscad/neoscad/releases).
